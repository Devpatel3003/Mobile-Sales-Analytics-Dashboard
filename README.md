# 📱 Mobile Sales Analytics Dashboard

## 📊 Project Overview

The **Mobile Sales Analytics Dashboard** is an interactive Power BI project designed to analyze mobile phone sales performance and provide business insights through data visualization.

The dashboard helps analyze sales, quantity sold, transactions, customer ratings, payment methods, mobile models, brands, cities, and sales trends over time.

---

## 🎯 Project Objective

The main objective of this project is to transform mobile sales data into an interactive dashboard that can help businesses:

- Monitor overall sales performance
- Analyze sales trends by month and day
- Compare sales across different cities
- Identify top-performing mobile brands and models
- Analyze customer payment preferences
- Understand customer ratings
- Track total quantity and transactions
- Support data-driven business decisions
